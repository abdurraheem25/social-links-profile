# Frontend Mentor - Social Links Profile

This is my solution to the [Social Links Profile challenge on Frontend Mentor](https://www.frontendmentor.io/challenges/social-links-profile-UG32l9m6dQ).

## Overview

The challenge was to recreate a social links profile card using the supplied design. The page presents a profile with links to different social platforms.

## Live links

- **Live Site:** https://abdurraheem25.github.io/social-links-profile/
- **GitHub Repository:** https://github.com/abdurraheem25/social-links-profile

## Built with

- HTML5
- CSS3
- Flexbox
- Responsive layout techniques
- GitHub Pages

## What I learned

While building this project, I practised:

- Structuring a page with separate HTML containers.
- Using Flexbox to align and arrange elements.
- Controlling card width with percentages and `max-width`.
- Creating a circular profile image with `border-radius`.
- Styling links as vertically stacked profile buttons.
- Using padding, spacing, background colours, and border radius.
- Adding hover and focus states to interactive links.

## Continued development

I want to keep improving my CSS layout skills, especially responsive design, spacing, and writing clean, maintainable styles.
